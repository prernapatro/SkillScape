 # Career AI App

 Full-stack career growth app scaffold:
 - Frontend: Next.js (dashboard UI)
 - Backend: Express (API endpoints)
 - Data: `/data` (datasets used by the backend)

 ## Run locally

 ### Backend
 ```bash
 cd backend
 npm install
npm run dev
```
Backend runs on `http://localhost:3001`.

If needed, copy `backend\.env.example` to `backend\.env`.

### Frontend
```bash
cd frontend
npm install
 npm run dev
 ```
 Frontend runs on `http://localhost:3000` and calls the backend API.

If needed, copy `frontend\.env.local.example` to `frontend\.env.local`.
